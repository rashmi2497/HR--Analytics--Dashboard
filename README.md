# HR Analytics Dashboard

## Project Overview
This project is an interactive HR Analytics Dashboard created in Microsoft Excel.

## Features
- Employee Count Analysis
- Gender Distribution
- Department-wise Analysis
- Performance Rating Analysis
- Joining Year Trends
- Interactive Slicers

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
